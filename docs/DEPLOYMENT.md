# Deployment Guide — ForgeCore Industries

## Cloudflare Pages (Recommended)

1. Connect the GitHub repository `ScaleNova-Pvt-Ltd/scalenova-demo-02-forgecore-industries`.
2. Configure build settings:
   - **Framework preset**: None
   - **Build command**: (Leave empty)
   - **Build output directory**: `/` (Root)
3. Deploy.

## GitHub Pages

1. Navigate to repository **Settings** -> **Pages**.
2. Select **Deploy from a branch** -> `main` branch -> `/ (root)`.
3. Save to trigger the GitHub Pages static deployment workflow.
